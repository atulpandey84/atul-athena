# Contributing to ATHENA

Thank you for your interest in contributing to ATHENA!

## Standards

This project follows strict engineering standards:
- SOLID principles
- Test Driven Development (TDD)
- Documentation First Development
- All architectural decisions must be recorded via ADRs.

## Workflow

1.  Identify the implementation phase you are working on.
2.  Create a branch for your changes.
3.  Ensure documentation is updated alongside code.
4.  Write and run tests.
5.  Submit a pull request.
